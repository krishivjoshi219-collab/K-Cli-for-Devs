## K-CLI Roadmap

> Track what's shipping next and what's planned.

### 🚢 v1.1 — Shipping Soon

- [ ] **`k-cli demo` command** — runs a fully automated no-API-key demo using Ollama  
- [ ] **Shell completions** — `k-cli --install-completion` for bash, zsh, fish  
- [ ] **`k-cli models pull <model>`** — stream Ollama model downloads with progress bar  
- [ ] **Plugin system** — load custom slash commands from `~/.k-cli/plugins/`  
- [ ] **Windows native support** — fix remaining path/terminal issues  
- [ ] **`k-cli watch`** — autonomous PR watcher daemon (polls GitHub every N seconds)  

### 🔭 v1.2 — On the horizon

- [ ] **More model providers** — Mistral AI, Together.ai, Cohere, Fireworks, Replicate  
- [ ] **VS Code extension** — sidebar panel that embeds K-CLI  
- [ ] **Team mode** — shared session with multiple devs hitting the same K-CLI agent  
- [ ] **`k-cli explain <file>`** — natural language walkthrough of any codebase file  
- [ ] **`k-cli optimize <file>`** — performance analysis + surgical rewrite suggestions  
- [ ] **Web dashboard** — optional browser view of the TUI session  

### 💭 Ideas (not committed)

- Slack/Discord bot integration  
- `k-cli doctor` — diagnose common setup problems  
- Multi-repo workspace support  
- LangChain / LangGraph pipeline builder
