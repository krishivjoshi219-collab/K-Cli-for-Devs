# The "Don't Be A Jerk" Code of Conduct 🤝

Hey! Welcome to the K-CLI community. We're all just fellow developers, hackers, and open-source enthusiasts trying to build cool AI tools that actually make coding fun again.

---

### The TL;DR:
1. **Be cool and respect each other**: Everyone comes from different backgrounds, time zones, and experience levels. Treat people like teammates, not code-review adversaries.
2. **Zero gatekeeping or elitism**: If someone asks a beginner question or submits slightly messy code, help them learn with friendly tips instead of roasting them. We were all there once.
3. **Disagree with code, not with people**: Constructive criticism on PRs is awesome! Just keep it kind, objective, and solution-focused.
4. **No harassment, discrimination, or drama**: We have zero tolerance for hate speech, bullying, trolling, or creepiness. Keep it friendly and focused on hacking.

---

### If something goes wrong:
If someone is being genuinely toxic or making you uncomfortable, shoot a message to the project maintainers or open an issue marked `[maintainer-private]`. We'll handle it quickly and quietly so you can get back to building.

Grab a coffee, build cool stuff, and have fun! ☕🚀
